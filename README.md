# 🤖 Portafolio de Aplicaciones de Inteligencia Artificial

Bienvenido al repositorio del **Portafolio de Aplicaciones de Inteligencia Artificial**. Este proyecto es una aplicación web desarrollada en **Streamlit** que reúne y presenta diversos proyectos interactivos basados en Inteligencia Artificial, Visión por Computador, Procesamiento de Lenguaje Natural y Análisis de Datos.

## 🚀 Proyectos Incluidos

La plataforma reúne las siguientes aplicaciones interactiva desplegadas:

| Categoría | Proyecto | Descripción |
| :--- | :--- | :--- |
| **Procesamiento de Audio** | 🗣️ Conversión de Texto a Voz | Transformación de texto escrito en habla natural de forma fluida y multimodal. |
| **Procesamiento de Audio** | 🎙️ Conversión de Voz a Texto | Transcripción de audio a texto en tiempo real con alta precisión. |
| **Generación & RAG** | 📄 Generación en Contexto (Chat PDF) | Chat interactivo con arquitectura RAG para realizar consultas basadas en documentos PDF. |
| **Visión por Computador** | 🔍 Reconocimiento de Objetos | Detección y localización de múltiples objetos mediante la arquitectura YOLO. |
| **Análisis de Datos** | 📊 Análisis de Datos con Agentes | Plataforma de analítica avanzada potenciada por agentes de IA para interpretación de datos. |
| **Visión por Computador** | 👁️ Análisis de Imagen Multimodal | Interpretación y análisis de imágenes usando modelos de visión avanzada (GPT-4o). |
| **Machine Learning** | 🧠 Entrenando Modelos | Demostración práctica del despliegue e interacción con modelos personalizados. |
| **Audio / Video** | 📝 Transcriptor Audio y Video | Herramienta de transcripción automática de medios utilizando OpenAI Whisper. |
| **Sistemas Ciberfísicos** | 🤖 Sistema Ciberfísico | Interacción entre algoritmos de visión por computador y entornos físicos. |
