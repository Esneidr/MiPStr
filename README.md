🌡️ Predictor de Sensación Térmica — Taller IoTAplicación interactiva desarrollada en Python con Streamlit que se conecta en tiempo real a una base de datos InfluxDB Cloud (con datos de temperatura y humedad medidos por un sensor ESP32 + DHT22), prepara la serie temporal, entrena un modelo de Regresión Lineal Multiple con scikit-learn y permite estimar la sensación térmica.🧩 Estructura y Funcionamiento del CódigoEl script está dividido en cuatro bloques principales:1. Funciones de Procesamiento y Machine Learningobtener_datos_crudos(...): Conecta a InfluxDB mediante InfluxDBClient, ejecuta una consulta Flux para extraer los campos de temperatura, humedad y sensacion_termica dentro del rango de horas elegido, convierte el índice a la zona horaria local (America/Bogota) y retorna un DataFrame con los datos tal como llegan.preparar_datos(...): Aplica interpolación por tiempo (method="time") para llenar posibles huecos o fallos puntuales de lectura del sensor y elimina valores nulos resultantes.detectar_outliers_iqr(...): Calcula el Rango Intercuartílico ($IQR = Q3 - Q1$) para identificar lecturas atípicas sin eliminarlas automáticamente.entrenar_modelo(...): Separa los datos en conjuntos de entrenamiento (70%) y prueba (30%), entrena el modelo de LinearRegression y retorna la ecuación junto con las métricas de desempeño ($MAE$, $RMSE$ y $R^2$).2. Panel Lateral (Sidebar)Permite ingresar las credenciales de acceso a InfluxDB (URL, Token, Organización, Bucket y Measurement).Incluye un deslizador (slider) para seleccionar el historial de horas a consultar (1 a 12 horas).Contiene el botón "🔄 Consultar datos y entrenar modelo", el cual dispara la consulta y almacena los resultados en el estado de la sesión (st.session_state).3. Métricas Principales en Tiempo RealCuando hay datos cargados, muestra tres tarjetas con la última lectura registrada por el sensor IoT: Temperatura (°C), Humedad (%) y Sensación Térmica real (°C).4. Pestañas de Análisis e Interacción📊 Estadísticos: Muestra la gráfica temporal del comportamiento de las variables, la tabla de estadísticas descriptivas (describe()) y gráficos tipo boxplot.🧹 Preparación de datos: Visualiza los tipos de datos, el porcentaje de faltantes, la curva de interpolación aplicada y el reporte de outliers según IQR.📈 Análisis del modelo: Muestra un gráfico de dispersión en 3D (matplotlib), la ecuación de regresión obtenida ($\text{sensación} = \beta_0 + \beta_1 \cdot \text{temp} + \beta_2 \cdot \text{hum}$) y las métricas de validación ($MAE$, $RMSE$, $R^2$).🔮 Predicción: Permite al usuario o estudiante ingresar sus propios coeficientes ($\beta_0, \beta_1, \beta_2$) calculados de forma independiente (por ejemplo, en Google Colab) y realizar predicciones ingresando valores manuales de temperatura y humedad.
